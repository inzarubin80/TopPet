# Матрица тарифов Free vs Pro

Константы в коде: [`Server/internal/tier/tier.go`](../Server/internal/tier/tier.go).

| Область | Free | Pro |
|---------|------|-----|
| Обложка карточки конкурса | Плейсхолдер | Своя `cover_url` |
| Выделение в ленте | Обычная карточка | Бейдж Pro / приоритет сортировки (UI) |
| Длина описания конкурса | до 2000 символов | до 20000 |
| Номинации | до 3 | до 100 |
| Критерии оценки жюри (на конкурс, общие для всех номинаций) | до 5 | до 100 |
| Жюри | до 2 человека | до 50 |
| Модерация заявок (`require_acceptance`) | недоступно | доступно |
| Платежи | — | разовая оплата ЮKassa за активацию Pro |
